# Agent Drafts

Findings / analysis an LLM / agent / workflow produced that a human has **not yet checked**.
Agents write here. Each file carries a provenance header:

```markdown
<!--
generated-by: <agent/model + skill if any>
generated-on: YYYY-MM-DD
from-run: <run_id(s) in docs/PROVENANCE.md>
from-notebook: <research/notebooks/...>
validation: PENDING — not yet reviewed by Liz
-->
```

**Only Liz promotes** a draft into `Human validated/`. The draft→validated diff is the record of
human judgment. Nothing here is a finding of epistemomechanics until it is promoted.
